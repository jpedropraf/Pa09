# UML

Está pasta contém os modelos **UML** utilizados para representar o sistema.

Podem ser armazenados aqui, conforme a necessidade do projeto:

- Diagrama de casos de uso;
- Diagrama de classe;
- Diagrama de sequência;
- Diagrama de atividade;
- Outro diagramas relevantes.

Os diagramas deverão acompanhar a evolução do sistema
