# Arquitetura

Esta pasta contém os documentos relacionados à **arquitetura do sistema**.

Conforme a evolução do projeto, deverão ser registrados:

- Arquitetura adotada;
- Componentes principais;
- Responsabilidades de cada componente;
- Relacionamento entre os componentes;
- Decisões relevantes relacionadas à arquitetura.

A documentação da arquitetura deverá ser **atualizada continuamente**, acompanhando a evolução do sistema.
